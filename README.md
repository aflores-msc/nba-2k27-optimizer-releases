# NBA 2K27 Build Optimizer

A desktop app for planning an NBA 2K27 MyCareer (MyPLAYER) build **before you spend VC**.
Pick a body, type the ratings you want after cap breakers, mark the ones you can't live without as
**Must**, and press **Find Best Build**. You get:

- the exact rating to set for all 21 attributes in the MyPLAYER builder,
- where each cap breaker (and specialization breaker) goes,
- the ratings you end up with, and which goals fall short if they can't all fit,
- the badges the finished build qualifies for.

The **Badges** tab shows all 53 badges as you type goals: the tier your goals reach, the best tier
your body can ever reach, and what the next tier needs.

## Download

Get the latest version from **[Releases](../../releases/latest)**:

| System | File |
|---|---|
| macOS (Apple Silicon: M1 or newer) | `NBA2K27-Optimizer-<version>-macOS-arm64.dmg` |
| Windows 11 (64-bit) | `NBA2K27-Optimizer-<version>-Windows-x64-Setup.exe` |

### First launch

The installers aren't signed with a paid certificate, so your computer asks once:

- **macOS**: open the `.dmg`, drag the app to Applications, then right-click it → **Open** →
  **Open**.
- **Windows**: if you see "Windows protected your PC", click **More info** → **Run anyway**.
